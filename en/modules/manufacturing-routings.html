Manufacturing routings

Define how each product is made.

The routing is the process recipe: which steps, in what order, on which machine, how long setup takes, what scrap to expect and which materials are consumed at each step.

Request a demoExplore modules
What’s included

Designed to be understood at a glance.

Sequence

Numbered steps, active version.

Add, edit and order steps. Each step is material consumption, activity or quality check, with its machine and times. Routings are versioned.

  • Routing versions (V.01, V.02…)
  • Default routing per product
  • Duplicate to another product
Materials per step

Each step knows which material type it uses.

Select the step’s material types: substrate, inks, plates, adhesive. Each order automatically shows its product’s matching materials.

  • One routing serves many products
  • Expected scrap and yield
  • Setup and estimated time

Everything you need in this module.

How it works

In four steps.

  1. Create the routing

    For a product or a family.

  2. Add steps

    With machine and times.

  3. Assign material types

    To consumption steps.

  4. Use it in orders

    Each PO picks it up.

FAQ

Questions about the manufacturing routings.

Can I have different routings per product type?

Yes. Every product type you make can have its own routing, with the steps and machines it really uses.

What happens to orders if I change a routing?

You create a new version; orders keep the version they were created with.

Does it work if I don’t make auto parts?

Yes. The steps are yours: cutting, assembly, welding, baking, filling or whatever your process needs.
